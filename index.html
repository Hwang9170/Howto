    막혔을 때

    자주 나오는 문제와 해결법
    "claude"(또는 git, node, vercel)을 찾을 수 없다고 나와요

    설치 직후라 터미널이 아직 몰라서 그래요. 터미널(또는 VS Code)을 완전히 껐다 켜세요. 그래도 안 되면 컴퓨터를 재시작하고, 그래도 안 되면 3단계 설치 명령을 다시 실행해 보세요.

    Copilot이 설명만 하고 파일을 안 만들어요

    채팅창 아래 모드가 질문(Ask)으로 되어 있어서 그래요. 에이전트(Agent)로 바꾸고 다시 요청하세요. 만든 뒤에는 Keep(유지)을 눌러야 파일이 저장돼요.

    Copilot이 "한도에 도달했다"고 나와요

    무료 플랜의 한 달 사용량을 다 쓴 거예요. 다음 달에 다시 채워지니 기다리거나, 계속 쓰고 싶으면 위에서 유료 트랙(Claude Code)으로 바꿔서 이어가도 돼요. 이미 만든 파일은 그대로 쓸 수 있어요.

    Claude Code를 쓸 수 없다고 나와요

    Claude 무료 플랜에서는 Claude Code를 쓸 수 없어요. claude.ai에서 Pro 이상인지 확인하세요. 다른 계정으로 로그인됐다면 /logout 후 /login.

    VS Code에 Claude 아이콘이 안 보여요

    VS Code를 재시작하거나 아무 파일이나 하나 열어보세요. 확장 목록에서 Claude Code가 켜져 있는지도 확인하세요. 안 되면 VS Code 터미널에서 claude를 실행해도 똑같이 쓸 수 있어요.

    Claude 앱에 Code 메뉴가 안 보여요

    앱을 최신 버전으로 업데이트하고, Pro 이상 구독인지 확인하세요. 앱 대신 휴대폰 브라우저에서 claude.ai/code로 들어가도 똑같이 쓸 수 있어요.

    Claude에서 내 저장소가 목록에 안 나와요

    GitHub 연결 때 저장소 접근을 허용하지 않아서 그래요. Claude Code 화면의 GitHub 연결(설정)에서 my-site 접근을 추가로 허용해 주세요.

    배포했는데 화면이 하얗거나 404가 떠요

    첫 화면 파일 이름 문제인 경우가 많아요. 파일 이름이 정확히 index.html인지 확인하세요. Claude에게 이렇게 물어봐도 돼요:

    배포했는데 화면이 안 나와. 원인 찾아서 고쳐줘
    배포할 때 이상한 폴더 경로가 나와요

    터미널이 사이트 폴더가 아닌 곳에 있어서 그래요. Ctrl+C로 취소하고, VS Code에서 사이트 폴더를 연 상태로 새 터미널을 열어 다시 하세요.

    에러 메시지가 무슨 말인지 모르겠어요

    에러 문구를 통째로 복사해서 Claude에게 붙여넣고 "이거 무슨 뜻이야? 해결해줘"라고 하세요. 제일 빠른 해결법이에요. 😉
